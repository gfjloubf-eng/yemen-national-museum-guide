## عن المشروع

موقع ويب متكامل يعمل كدليل رقمي رسمي للمتحف الوطني اليمني. يهدف الموقع إلى:

- عرض 120 قطعة أثرية من مختلف العصور اليمنية
- استعراض 8 حضارات يمنية (سبأ، معين، قتبان، أوسان، حضرموت، حمير، العصر الإسلامي، اليمن الحديث)
- توفير 15 قاعة عرض تفاعلية في 3 أدوار
- تمكين البحث والفلترة المتقدمة
- توفير خريطة تفاعلية للمتحف
- دعم الباحثين بملاحظات البحث والمراجع العلمية

## الميزات

### 🧭 للزوار
- تصفح القطع الأثرية مع صور وتفاصيل كاملة
- بحث نصي متقدم في جميع الحقول
- فلترة حسب الحضارة، القسم، العصر، الدور، المحافظة، المادة
- إضافة القطع إلى المفضلة (محفوظة في المتصفح)
- خريطة تفاعلية للمتحف مع التنقل بين القاعات
- خط زمني تفاعلي للأحداث التاريخية
- عرض القاعات والأدوار

### 🔬 للباحثين
- جميع ميزات الزوار
- ملاحظات بحثية محفوظة محلياً
- مراجع علمية لكل قطعة
- صور إضافية عالية الدقة

### 🛠️ للإدارة
- لوحة معلومات مع إحصائيات حية
- رسوم بيانية (توزيع القطع حسب الحضارة، القسم، الدور)
- جدول القطع الأثرية مع البحث
- إدارة المستخدمين
- رفع الصور (واجهة)
- الأقسام والفئات

## الاستخدام

### المتطلبات
- متصفح ويب حديث (Chrome، Firefox، Edge، Safari)
- اتصال بالإنترنت (لتحميل المكتبات من CDN)

### التشغيل
1. افتح الملف `index.html` في المتصفح
2. استخدم القائمة العلوية للتنقل بين الصفحات
3. حسابات تجريبية:
   - **مدير**: `admin` / `admin123`
   - **باحث**: `researcher` / `res123`
   - **زائر**: `visitor` / `vis123`

### ملاحظات
- المفضلة والملاحظات البحثية محفوظة في `localStorage` بالمتصفح
- توجد الآن 26 صورة حقيقية منظمة تحت `assets/images/photos/` (WebP محسّن + مصغرات + الأصول الأصلية)، مع فهرس `image-manifest.json` وتقرير `reports/image_organization_report.md`
- الصور الـ SVG وهمية وتستخدم كبدائل/هياكل مؤقتة للتصميم
- لا يتطلب المشروع أي خادم خلفي — يعمل بالكامل من المتصفح
