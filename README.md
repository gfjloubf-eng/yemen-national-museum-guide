## عن المشروع

موقع ويب متكامل يعمل كدليل رقمي رسمي للمتحف الوطني اليمني. يهدف الموقع إلى:

- عرض 120 قطعة أثرية من مختلف العصور اليمنية
- استعراض 8 حضارات يمنية (سبأ، معين، قتبان، أوسان، حضرموت، حمير، العصر الإسلامي، اليمن الحديث)
- توفير 15 قاعة عرض تفاعلية في 3 أدوار
- تمكين البحث والفلترة المتقدمة
- توفير خريطة تفاعلية للمتحف
- دعم الباحثين بملاحظات البحث والمراجع العلمية

## الاستخدام

### الوضع الأول: بدون خادم (SAFE mode)
- متصفح ويب حديث (Chrome، Firefox، Edge، Safari)
- اتصال بالإنترنت (لتحميل المكتبات من CDN)
1. افتح الملف `index.html` في المتصفح مباشرة
2. الواجهة تحاول الاتصال بالـ API أولاً؛ إذا لم يتوفر الخادم تتحول تلقائياً إلى تحميل ملفات `data/*.json` محلياً (وضع الأمان)

### الوضع الثاني: مع الخادم الخلفي (Milestone 9)
المتطلبات: **Node.js 18+** (تم اختباره على v24.15.0)

```bash
# تثبيت التبعيات
cd backend
npm install

# تشغيل الخادم (ينشئ قاعدة البيانات ويستورد JSON تلقائياً)
npm run dev
# أو
npm start
```

ثم افتح <http://localhost:3000> — الخادم يقدّم الواجهة الأمامية ونفس واجهة REST API:
- `GET /api/home` — البيانات المجمّعة للرئيسية
- `GET /api/exhibits` — كل القطع الأثرية (120)
- `GET /api/exhibits/:id` — تفاصيل قطعة
- `GET /api/civilizations` — الحضارات (8)
- `GET /api/halls` — القاعات (15)
- `GET /api/floors` — الأدوار (3)
- `GET /api/events` — الأحداث التاريخية (20)
- `GET /api/figures` — الشخصيات التاريخية (30)
- `GET /api/users` — المستخدمون (بدون كلمات المرور)
- `POST /api/login` — التحقق من بيانات الدخول على الخادم
- `GET /api/search?q=...` — البحث النصي
- `POST /api/contact` — حفظ رسالة من صفحة "اتصل بنا" في SQLite

### حسابات تجريبية
- **مدير**: `admin` / `admin123`
- **باحث**: `researcher` / `res123`
- **زائر**: `visitor` / `vis123`

### ملاحظات
- المفضلة والملاحظات البحثية محفوظة في `localStorage` بالمتصفح
- رسائل نموذج "اتصل بنا" تُحفظ في `backend/database/museum.db` (جدول `contact_messages`) وتستمر عبر إعادة التشغيل
- توجد الآن 26 صورة حقيقية منظمة تحت `assets/images/photos/` (WebP محسّن + مصغرات + الأصول الأصلية)، مع فهرس `image-manifest.json` وتقرير `reports/image_organization_report.md`
- الصور الـ SVG وهمية وتستخدم كبدائل/هياكل مؤقتة للتصميم
